# ERC-8183 conformance notes

Spec: https://eips.ethereum.org/EIPS/eip-8183 (draft). Where its prose and its reference code differ, Chainwork follows the prose.

## Conformant

- `JobStatus { Open, Funded, Submitted, Completed, Rejected, Expired }` and the `Job` struct, unchanged.
- Core functions: `createJob`, `setProvider(jobId, provider, optParams)`, `setBudget`, `fund(jobId, expectedBudget, optParams)`, `submit`, `complete`, `reject`, `claimRefund`, `getJob`.
- Events as in the spec (with `indexed` and `hook` in `JobCreated`, as the reference does).
- Hooks: `IACPHook.beforeAction/afterAction` on `setProvider, setBudget, fund, submit, complete, reject`; `claimRefund` is never hooked.
- Evaluator rules: in `Open` only the client may reject; in `Funded` only the evaluator may reject; in `Submitted` only the evaluator may complete or reject.
- `claimRefund` valid when `Funded` or `Submitted` and `block.timestamp >= expiredAt`; callable by anyone.
- No platform or evaluator fees (both 0). Refunds never carry fees.

## Deviations and extensions

| Item | Spec / reference | Chainwork | Why |
|---|---|---|---|
| `fund` budget check | prose: `expectedBudget`; reference: none | prose form | front-running protection |
| Hook whitelist | reference only | none; hooks are per job and chosen by the client | client owns its own guard |
| Acceptance | not in spec | `acceptJob` required before `submit`; posts the reputation-priced bond | bonds |
| Gasless funding | ERC-2771 suggested | `fundWithAuthorization` via tUSD8 EIP-3009, nonce = terms hash | native to tUSD8, front-run safe |
| Children | not in spec (thread discusses linked jobs) | `createSubJob` carves budget from a Funded parent; depth 1; 4 children | subcontract trees |
| Child refunds | refund goes to client | a child's refund returns to the parent's budget pool, not to a wallet | no new money in trees |
| Optimistic completion | not in spec | `challengeWindow`, `challenge`, `finalize` | async verification |
| Instant completion | evaluator may be a contract | separate `verifier` + `submitWithProof` | verifier needs no evaluator role |
| Expired with open children | n/a | `claimRefund` on a parent reverts `ChildrenOpen` until children are closed; children always expire first, so the refund can't be blocked | invariant I5 |
